## 境界

- `CharacterDirector`は従来どおり`CharacterMood`だけを決定する
- Moodから表情番号への変換はPresentationの`pixiRenderer.ts`で行う
- Sprite Loaderは表情PNGを個別に読み込み、欠損時は通常立ち絵へ縮退する
- 表情追加のために入力Adapter、世界シミュレーション、イベント発生条件は変更しない

## 生成条件

同一キャラクター・向き・姿勢・配色・衣装・縮尺を固定し、顔と小さな頭部姿勢だけを変更。4枠横一列、均一クロマ背景、文字・背景・影・小道具なしで生成し、透過処理後に共通縮尺と下中央アンカーへ揃えた。
