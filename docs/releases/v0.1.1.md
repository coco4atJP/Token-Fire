# Token Fire v0.1.1 — unsigned preview

Codexが生成Tokenを使うと小さな工場が動き、待機中は雨と植林で静かに回復するデスクトップ玩具です。表示は24段階のふわっとした相対表現で、実測の電力・CO₂・水使用量ではありません。

## インストール

- Apple Silicon Mac: 添付の `aarch64.dmg` を選び、アプリをApplicationsへコピーします。
- Intel Mac: 添付の `x64.dmg` を選び、アプリをApplicationsへコピーします。
- Windows x64: 添付の `x64-setup.exe` または `.msi` のどちらか一方を実行します。

Codex DesktopまたはCLIのローカルJSONLを読み取ります。Node.jsやRustのインストールは不要です。起動後はDEMOで表示を試し、CODEXへ切り替えてCodexでタスクを実行してください。

## 初回起動について

この初期公開版にはApple Developer ID署名・公証とWindowsコード署名がありません。macOSには証明書不要のad-hoc署名だけを付けています。起動時に警告または実行拒否が出ることがあります。

- macOS: Applicationsへコピーして一度起動した後、出所を確認したうえで「システム設定 → プライバシーとセキュリティ → このまま開く」からアプリ単位で許可できます。[Appleの説明](https://support.apple.com/ja-jp/102445)
- Windows: SmartScreenに「詳細情報 → 実行」が表示される場合は、出所を確認したうえで進められます。Smart App Controlや組織のポリシーでは未署名アプリを実行できない場合があります。[Microsoftの説明](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation)

OS全体のセキュリティ保護を無効にする必要はありません。許可できない環境での動作は保証していません。添付の`SHA256SUMS`でダウンロード内容を照合できます（発行元の身元を証明する署名の代わりではありません）。

## 操作と保存

- PLAYでキャラクターを操作し、DONEまたはEscapeで戻ります。
- LEDGERで記録・Replay・設定を開き、QUIETで30分休止します。
- 閉じるボタンはTrayへ隠します。終了はTrayメニューから行います。
- `Cmd/Ctrl + Shift + F` でウィンドウを表示できます。
- 世界と設定は端末のWebViewストレージへ保存します。LEDGERの「全事業所データ」でJSONを書き出せますが、JSONを復元する読込UIはありません。

## 更新と既知の制限

旧公開版からのupgrade、再インストール・アンインストール後のユーザーデータ保持は未検証です。

自動更新はありません。次版のGitHub Releaseをダウンロードし、Trayから終了してから更新してください。更新前のJSON出力は記録用であり、完全なバックアップ／復元機能ではありません。

Fullscreen・画面共有・OSの集中モードとの自動連動は保証していません。必要に応じてQUIETまたはミュートを使用してください。GPU固有差、複数モニター、実sleep復帰は検証範囲に制限があります。Codexのログ形式変更で検出が縮退する場合があります。Replay動画を生成できない場合はJSONへ切り替わります。

任意の天気連動を有効にした時だけ、手入力の座標を天気サービスへ送信します。自動telemetryやクラッシュ送信はありません。
